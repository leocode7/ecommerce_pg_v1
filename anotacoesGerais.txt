------ SUBIR CONTAINER(quando o arquivo compose estiver na raiz): $
docker compose up -d

------ SUBIR CONTAINER(quando o arquivo compose estiver não estiver na raiz) - usar o --file ou -f: $
docker compose -f src/infra/compose.yaml up -d

------ DERRUBAR CONTAINER (quando estiver na raiz): $
docker compose down

------ DERRUBAR CONTAINER (quando estiver fora da raiz): $
docker compose -f src/infra/compose.yaml down



----- ESTRUTUTA DO ARQUIVO compose.yaml:

services: 
  database:
    image: 'postgres:18.6-alpine3.24'
    environment:
      POSTGRES_PASSWORD: 'local_password'
    ports:
      - '5432:5432'    // portaHost(fora do banco)/portaGuest(do container)


---- VARIÁVEIS DE AMBIENTE --------
Ao digitar algo no terminal, ele fica gravado no log do terminal e pode ser vizualizado através do $history.
Para não registrar no log do terminal, só digitar um espaço antes de iniciar a digitar o comando.
Apagar tudo do history: $history -c && history -w
